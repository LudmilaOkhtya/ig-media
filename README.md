# ig-media

**Публичный репозиторий-транспорт для медиа, публикуемого в Instagram. Ничего больше.**

Единственное назначение: временно отдать один конкретный фото- или видеофайл
по прямой ссылке `https://raw.githubusercontent.com/<owner>/ig-media/main/<файл>`,
чтобы Instagram Graph API мог скачать его без авторизации.

## Правила (обязательные)

1. Сюда кладётся **только** конкретный медиафайл (`.jpg`, `.jpeg`, `.png`, `.mp4`,
   `.mov`), который владелец **явно выбрал** для публикации в Instagram.
2. **Перед каждой загрузкой** ассистент показывает владельцу имя файла и
   целевой Instagram-аккаунт и ждёт явного подтверждения.
3. Сам пост в Instagram публикуется **только после отдельного явного
   подтверждения** владельца.
4. **После успешной публикации файл удаляется** из репозитория отдельным
   коммитом. В штатном состоянии здесь лежат только `README.md` и `.gitignore`.
5. Сюда **никогда** не попадают: токены, ключи, `.env`, конфиги, исходный код,
   личные документы, архивы, любые файлы кроме перечисленных медиа-расширений.
   Это дополнительно закреплено в `.gitignore` (deny-all + белый список).

## История

Git хранит историю: удалённый из ветки файл остаётся в старых коммитах.
Для транспортного медиа это приемлемо (Instagram его и так публикует).
Если нужно вычистить полностью — `git filter-repo` + принудительный push,
либо пересоздать репозиторий.
